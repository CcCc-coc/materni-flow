# Syllabus

Build an AI Agent for fintech lending analytics. This course teaches you how to create Agents that query databases, understand business context, and generate insights—skills that transfer to any AI Agent project.

## 01-Project-Overview

Introduction to SMB Lending Lens—a fintech AI Agent that helps analysts query loan data using natural language. Learn the universal pattern behind AI Agent projects: Database + Tools + Prompt + Context + Workflow. Understand why mastering one Agent project enables rapid development of future projects (first project: 1 month, second: 1 week).

## 02-Data-Exploration

Deep dive into the lending database through 4 key documents: project overview, table structure walkthrough, ER diagram, and 20 business SQL queries. Learn systematic data exploration methodology, understand the 4-tier table dependency structure, distinguish direct fields from derived metrics, and practice SQL with AI assistance using DBeaver.

## 03-The-System-Prompt

Master the art of system prompt design by studying a production prompt and its source materials. Learn what to include (business-specific definitions, calculated metrics, domain rules) versus what to omit (basic concepts the model already knows). Understand the "balance" principle: too little guidance causes hallucinations, too much causes confusion. Practice comparing the condensed prompt against verbose source documents to see prompt engineering in action.
