# 换行业的 AI 数据分析脚手架 自测

> showcase-quiz-cn skill 靠这份文档找到题库, 并知道该怎么考. 题目本身不在这里, 在它指向的那个 Task 里.

## 1. 题库位置

题库就是 quiz 那个 Task 的 README: [examples/41-prove-i-get-it](../../examples/41-prove-i-get-it/README-cn.md). 里面有 **51 道题**, 覆盖整门课的要点.

它模拟的是一个具体场景: 你花十五分钟 walkthrough 完这个代码库之后, 面试官开始追问. 所以判据不是你答得出定义, 是你答得出**为什么不是另一种做法**.

题目按四块分布: 数据那一块 (数据集, 建库, 同步, 库结构编码, SQL 工具) 约 38%, AI 那一块 (直接调模型, agent 组装, 提示词, 解析, 全链路) 约 38%, 设计与工程 (`one`, config, 测试, 检查, 配额, 契约) 约 17%, 前端约 7% 且**只问它在哪, 不问怎么实现**.

每道题都带一个溯源链接指回对应的主线 Task. 51 道题打到了 29 篇主线.

## 2. 考法自定义

没有特殊要求, 按 showcase-quiz-cn skill 默认来.

两条这份题库自带的性质, 考的时候顺带知道就行:

- **难度不标.** 清单里有几道明显比别的难, 但面试官不会先告诉你这题难, 标了反而破坏模拟.
- **第四类题最要紧.** 一个照着教程抄的人答得出前三类 (指得出东西在哪, 知道为什么这么做, 知道不这么做会怎样), 答不出第四类 —— **分得清哪些是你自己的判断**.

及格线 70%.
