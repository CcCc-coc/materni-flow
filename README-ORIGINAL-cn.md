# learn_smb_lending_lens_v1-project

用自然语言查数据库这件事, 过去二十年换过三代做法, 前两代都卡在同一个地方: 报表答不了没被预先设计过的问题, 拖拽式 BI 只是给 SQL 换了个界面. LLM 解开的正是这一处, 于是真正的难题变成了另一个 —— **怎么让模型知道你这个库长什么样, 你这一行的黑话是什么意思.** 这门课造的就是回答这个问题的那套东西: 一个多表 PostgreSQL 数据库, 一个能用大白话查它的 agent, 和一个把这门生意讲给外行听的网站.

但它真正教的不是怎么写一个 chatbot. **它教的是怎么造一个能反复换行业的脚手架, 并且守住让它能换的那些边界.** 这个区别是整门课的重心: 一个作品只能投一次, 一个脚手架每次投递都能长出一个新作品. 学完你手上是一个部署在自己域名上, 别人点开就能用的应用; 更要紧的是你知道它凭什么能在一两个小时之内换成另一个行业, 以及每一条边界破了会怎样 —— 而这些边界的共同点是, 破了通常**不报错**, 只是答案悄悄变差. 认得出这一类失败, 是这门课想留给你的东西里最耐用的一样.

这门课的形态是一个仓库同时装着两样东西: 那个应用, 和教你怎么造出它的课. 教学内容在 `examples/` 下按编号排开, 从零门槛的第一次跑通, 到读懂界面, 接上真数据和真模型, 再到把 agent 拆开一层层看, 最后送上线, 换一个行业验证它真的可复用. 走完之后教学痕迹整块删掉, 剩下的就是你自己的作品仓库 —— 这也是它被设计成 showcase 而不是一份读完就完的教程的原因.
