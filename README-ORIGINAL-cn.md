# learn_smb_lending_lens_v1-project

这是一个你亲手搓出来的 **AI Agent 应用**, 但它不是一个玩具: 部署走的是真实的云平台, 架构, 边界与检查全部按企业级的来. 它由几样很不一样的东西咬合在一起 —— 一个多表的真实数据库, 一个会自己写 SQL 去查它的 agent, 一个把这门生意讲给外行听的网站, 加上一整条从本地到公网的链路. 换句话说, **它天然是一个多领域交叉的 App**, 所以你几乎一定会在里面撞见自己从没碰过的领域. 而这恰恰是它值得做的原因: 每一块都通到能跑, 每一块都能很快上手. **这就是 AI 时代做一个项目的样子 —— 你什么都会一点, 然后按需要挑一个方向, 在那一块上成为深度专家.**

它干的事情是**商业分析**, 但那个商业不特指哪一行: 今天这份数据是小微企业放贷, 换成医疗, 金融, 科技, 广告或者能源, 它就是那一行的应用. 所以这门课真正教的不是怎么写一个 chatbot, 而是**怎么造一个能反复换领域的脚手架, 并且守住让它能换的那些边界**. 一个作品只能投一次, 一个脚手架每次投递都能长出一个新的 —— 投简历之前花四个小时, 它就能变成那家公司的专属项目. 而这件事能成立, 靠的是一堆破了通常**不报错** 的边界: 提示词里一个过期的数字, 一个悄悄被换掉的分母, 一份只改了一半的内容 —— 程序照跑, 测试全绿, 只有答案悄悄变差. 认得出这一整类失败, 是这门课想留给你的东西里最耐用的一样.

这门课的形态是一个仓库同时装着两样东西: 那个应用, 和教你怎么造出它的课. 教学内容在 `examples/` 下按编号排开, 从零门槛的第一次跑通, 到读懂界面, 接上真数据和真模型, 再到把 agent 拆开一层层看, 最后送上线, 换一个领域验证它真的可复用. 走完之后教学痕迹整块删掉, 剩下的就是你自己的作品仓库 —— 这也是它被设计成 showcase, 而不是一份读完就完的教程的原因. **先打个预防针: 这个模块很大, 非常硬核.** 但它全程有一个为它定制的 AI 陪着你, 你一定走得完.
