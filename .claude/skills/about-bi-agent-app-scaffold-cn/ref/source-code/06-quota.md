# 月度花费上限

对应代码: `agent_app/quota.py`

---

## 为什么存在

一个谁都能打开的 chat agent 是一张敞开的账单: 每条消息都在花某人云账号里的钱。这个模块
按自然月统计调用次数和 token 数, 到顶就拒绝开始新的一轮。

**默认关闭.** 本地跑的人花的是自己的额度, 不需要上限; 而且打开它需要一张 DynamoDB 表, 那
张表在有人去建之前并不存在。它是给**公开部署**用的 —— 付钱的人和打字的人不是同一个人的
那种场合。

---

## 什么可配, 什么不可配

**可配** (随部署变, 在 `.env` / `.env.defaults`): 开关、表名、三个上限。

**不可配** (写死在代码里): 那四个 DynamoDB 属性名, 以及 partition key 的形状。

partition key 是三段, 用 `:` 分隔:

```
learn-bi-agent-app-scaffold : fintech_smb_lending_pipeline_medium : 2026-08
        脚手架                          数据集                        月份
```

- **脚手架** = `SCAFFOLD_ID` 常量。它标识**这个代码库**, 换数据集不变, 所以既不该进
  `dataset` 配置也不该进 `.env` —— 按仓库的判据 (换个业务领域要不要改?), 不改就归脚手架,
  也就是代码里的一个常量。只有 fork 或重命名脚手架时才动它。
- **数据集** = `config.schema_name`. 那正是随数据集变的东西, 而且它本来就必须全局唯一
  (不唯一就撞别的项目的表)。
- **月份** 让新的一个月自动从零开始, 不需要任何人去重置。

用 `:` 而不是 `-` 拼接, 是因为 slug 里有连字符、schema 名里有下划线, 用 `-` 粘会造出
"看不出名字在哪结束"的歧义。现在这个 key 能 `split(":")` 拆回三段, 在控制台里能读。

**曾经有第二个标识符.** `data/dataset.toml` 里的 `[project] name = "smbll"` 也在做这件事,
那是表名前缀时代的残留 —— 前缀退役之后它唯一的工作就是当配额 key. 一个东西两个名字, 就是
两个要同步维护的东西, 所以合并到了 `schema_name`.

一张 DynamoDB 表可以装很多个部署的计数器, 理由和一个 Postgres 库可以装很多项目的表一样。

---

## 为什么是裸 boto3 而不是 ORM

item 只有四个属性, 而且不会再多。ORM 在这里只会换来三个依赖。`boto3` 本来就是核心依赖。

每个函数都显式接收 `boto_ses` 和 `config`, 而不是去抓 `one` 单例。这让这个模块可以单独
import, 让测试能用桩驱动它 (`tests_python/test_quota.py` 一个 AWS 调用都没有), 也避免为了
读三个数字而再建一个 `Config`.
