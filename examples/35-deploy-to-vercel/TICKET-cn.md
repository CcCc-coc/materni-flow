# 把它送上公网

## 1. 目标

这是主题 8 的第一篇, 也是这个项目第一次离开你自己那台电脑.

在此之前, 出了问题你总能加一句打印, 总能看着终端一行行滚. 上线之后这些全没了: 你只有一份
构建日志和一个用户说不太对.

**这一篇要抓住的那句话是:** 本地跑得起来和云上跑得起来, 差的不是代码, 是环境. 你机器上那些
你从来没意识到自己在依赖的东西, 云上一个都没有.

**最值得慢慢读的是第 9 节那一行代码.** 它讲的是调试输出为什么必须走 stderr. 那个坑本地
复现不出来, 线上也不报错, 只是某一段回答莫名其妙少了一截.

**这一篇假设你已经部署过一个 Next.js 应用了.** 前身那门课
(`learn_personal_portfolio_ai`) 的 `05-Deploy-Hello-World-NextJs-App-to-Vercel` 和
`13-Env-Vars-and-Deployment` 讲的就是这件事. 导入仓库, 触发构建, 看部署日志这些这里不重讲,
卡在那一层就回去翻那两篇.

**这一篇真正新的只有两件**: 这个仓库有两半 (Python 和 TypeScript 会被拆成两样东西), 以及
**环境变量在这里是三层而不是一两个值**. 第二件是重心, 占了第 7 和第 8 两节.

**第 7 节那个截图给 AI 核对的动作别跳过.** 环境变量有三种错法, 在终端里报出来的现象完全
相同, 而用眼睛读自己的配置很难发现 —— 因为你是照着自己的记忆在读, 而记忆正是错的来源.

**卡住了别硬扛.** 把这些一起给 AI: 你在读哪一篇的路径, 你敲的那条命令,
**终端或者构建日志打出来的原文** (整段复制), 以及**一张当前页面的截图**. 这一篇一大半的
状态在网页上而不在终端里, 所以截图比描述准得多.

**截图里变量名可以给, 值不行.**

## 2. 要做的事情

1. 读完 README, 重点是第 7 节那张三层配置表和第 9 节那一行代码.
2. 确认本地 agent 还能答. 云上不会修好一个本地就坏着的东西.
3. 把当前分支推到 GitHub, 确认你要部署的是哪一个分支.
4. 在 Vercel 上从 GitHub 导入这个仓库. 这一步你在前身那门课做过, 卡住就回去翻那一篇.
5. 按第 7 节那张表把要手填的环境变量一条条填进去, 每一条都确认**生产那一栏勾上了**.
6. **截一张环境变量页面的图**, 连同两个配置文件的内容, 按第 7 节那段提示词交给 AI 逐条核.
7. 按它列出来的问题逐条修, 修完再触发第一次部署.
8. 等构建结束, 用 `curl` 打一次 `/api/hello`, 确认返回那段 JSON.
9. 打开首页点一个 kickstart 问题, 确认 agent 真的答了.
10. 对 README 练习 2 那六个变量, 各回答它在云上从哪来, 以及漏了会怎样.
11. 回答一句: 有人把 `SCHEMA_NAME` 也填进环境变量页面会发生什么.
12. 打开 `agent_app/utils.py` 找到 `debug`, 说清它走 stderr 而不是 stdout 的理由.
13. 决定要不要现在就打开那道花费闸门, 并说出你的判据.

**预计用时:** 60 到 100 分钟

## 3. 检查清单

- [ ] **它在公网上活着**: 你有一个 `.vercel.app` 地址, 首页能打开, 点一个问题 agent 真的答了.
- [ ] **后端单独验过**: 你用 `curl` 打过 `/api/hello` 并拿到了那段 JSON, 也能说清这一条通了
      排除掉了哪些可能.
- [ ] **三层配置分得清**: 对那六个变量你都答出了它从哪来, 并且和 Vercel 页面上的实际情况
      对上了.
- [ ] **截图核对过**: 你把环境变量页面截图连同两个配置文件交给 AI 逐条核过并按它的清单改过,
      能说出那三种在终端里长得一模一样的填错方式, 也确认过每条变量都作用于生产环境.
- [ ] **覆盖这件事**: 你能说清把一个 committed 的默认值也填进环境变量页面会怎样, 以及为什么
      这种覆盖在 `git diff` 里看不见.
- [ ] **没有家目录**: 你能解释同一对 AWS 变量为什么本地必须留空而云上必须填满, 理由要落在
      环境变量赢过配置文件这条规则上.
- [ ] **stdout 那一条**: 你能说清 serverless 上 stdout 通向哪里, 以及一句 `print` 会怎么
      悄悄弄坏一次回答.
- [ ] **部署不是拷文件**: 你能说出一次部署实际做的三件事, 并解释为什么本地装过但没写进依赖
      清单的东西在云上不存在.
- [ ] **成本模型变了**: 你能说清上线之后为什么才需要花费上限, 并说出你自己那个判据.
