# 换一个行业

## 1. 目标

这是这门课的兑现时刻.

前面三十几篇讲的每一条边界听起来都有点抽象: 文件名为什么要靠发现, 表名为什么两边必须一样,
文案为什么不能写在组件里. 每一条单独看都像洁癖.

**这一篇把账一次算清.** 换完之后跑一次 `git diff --stat`, 你会看到 `agent_app/` 下面零个
文件被改 —— 那个数字就是前面所有洁癖的收益.

**要抓住的那句话是:** 换到一半的状态是能跑的, 能构建, 测试全绿, 它只是全程在撒谎. 而没有
任何自动检查能发现这件事.

**这一篇你实际动手的只有三件事**: 把新数据集那五份文档放进 `dataset/`, 回答 AI 中途问的
几个问题, 然后自己点开网站验收. 中间那一大段改动是一条 skill 带着 AI 做的 —— 第 7 节讲
skill 是什么, 以及为什么这件事值得交出去: 一次换数据集要保持一致的点有三十几个,
**人读一遍清单只能记住五条**.

**但第三件不能交出去.** skill 能保证每一处都被改到, 保证不了改得对.

**练习 2 是这一篇真正的重点.** 拿下游的产物回上游找出处, 是检验一条推导链有没有被真正执行
的唯一办法.

**动手之前先开分支.** 这一篇改的文件比前面任何一篇都多, 而且中间有一大段是 AI 在写.
Vercel 部署的是默认分支, 所以在这个分支上折腾不会影响你的线上地址.

**卡住了别硬扛.** 把三样东西一起给 AI: 你在读哪一篇的路径, 你敲的那条命令, 以及
**终端打出来的原文** (整段复制). 这一篇还要多说一句你卡在十步里的第几步.

## 2. 要做的事情

1. 读完 README, 重点是第 6 节那个全程撒谎的状态, 第 7 节 skill 是什么, 和第 9 节那条串行推导链.
2. 开一个叫 `37-swap-the-dataset` 的分支, 确认你不在 `main` 上.
3. 把 `dataset-for-swap/` 里那五份文档复制进 `dataset/`, 删掉旧的那五份, 留下依赖清单.
4. 删掉旧的产物: 那个 `.sqlite` 文件和 `dataset/data/` 下的 `.tsv`. 这一步不能省.
5. 敲 `/run-swap-dataset-phase-1-cn`, 跟着走. 它中途会问品牌名和 agent 叫什么, 想好再答.
6. 走到闸门之后跑 `mise run cli-check-content` 和 `mise run build-web`, 两个都要过.
7. 再跑一次带退休词表的那条, 逐个看它报出来的残留并改掉.
8. **自己点开网站看一遍**, 确认首页说的是排班, 并问两个问题看答得对不对.
9. 跑 `git diff --stat`, 数一数 `agent_app/` 下面有几个文件被改.
10. 打开新的 `data/site.toml`, 挑 4 条听起来最具体的 kickstart 问题.
11. 对每一条回新的 `data/system-prompt.md` 的分析索引里找出处, 按那三种结果分类.
12. 回答一句: 如果真想给首页多加一个分析, 正确的起点是哪个文件, 为什么不能反过来.

**预计用时:** 90 到 150 分钟

## 3. 检查清单

- [ ] **换完了而且验过了**: 三条验证命令都过, 你也亲手点开网站问过问题, 确认它说的是新行业
      的话.
- [ ] **那个数字**: 你跑过 `git diff --stat`, 确认 `agent_app/` 下面零个文件被改, 并能说清
      这个零是被哪几条边界撑住的.
- [ ] **三样东西**: 你能说出必须同时换的是哪三样, 各住在哪, 以及只换其中两样会产生什么现象.
- [ ] **skill 是什么**: 你能说清它是一份提交进仓库的写给 AI 的操作手册, 说出这件事为什么值得
      写成 skill, 以及它保证得了什么保证不了什么.
- [ ] **全程撒谎**: 你能解释那个状态为什么不报错, 理由要落在每个环节单独看都自洽这件事上.
- [ ] **为什么两条命令**: 你能说清拆开的理由和模型上下文被压缩有什么关系, 以及阶段二为什么
      值得清空之后再敲.
- [ ] **串行推导与那条铁律**: 你能复述那五步, 说清第二步为什么不许回头翻源文档, 并能判断一个
      想加的分析该从哪个文件开始加.
- [ ] **追溯做过了**: 你对 4 条 kickstart 问题都找过出处并分了类, 也能说清出现即兴发挥那一
      类时用户会看到什么, 以及为什么没有任何检查会拦住它.
- [ ] **两个检查各管一半**: 你能说出内容检查和构建各抓什么, 以及那个退休词表为什么是一次性
      的参数而不是 committed 的配置.
