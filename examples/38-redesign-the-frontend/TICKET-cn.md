# 换完内容, 再换衣服

## 1. 目标

这是这门课里唯一一篇**鼓励你大改** 的内容, 而它同时要求你把手停在三个地方.

这个组合比听起来难. 一个只说别乱改的规矩好守, 一个只说随便改的规矩也好守. 难的是同时接受
这两句话, 并且在每一次具体的改动前判断自己站在哪一边.

**那个判据其实很朴素:** 看这个东西内部有没有你看不见的状态. 颜色, 间距, 圆角, 布局都是你
看得见的, 改坏了当场就知道. 焦点, 滚动, 流式, 契约改坏了要过很久, 而且往往是别人替你发现的.

**开工之前先清空上下文.** 阶段一结束时对话里塞满了源文档和文案草稿, 那些对视觉设计没用, 但
它们还占着位置. 该知道的东西全在文件里, 清掉不丢任何东西.

**第 6 节那五个维度里, 构图那一条最容易漏.** 前四样都定了而构图没定, 结果就是换了颜色的
同一个页面.

**你不用会写 React, 也不用装任何东西.** 视觉这一层是十几个 React 组件加一套 Tailwind 配置,
不做前端的人打不开就知道改哪一行 —— 而这门课从来没打算教你 React.
**这一步的正确姿势是带着 AI 动手**: 你定调性, 守边界, 逐页验收; AI 找文件改样式.

**但有一件事必须自己确认**: 那个管视觉的 skill 真的进了上下文没有. 它没加载不报错, 你只是
会拿到一个长得像所有 AI 生成页面的东西. 第 7 节给了确认的问法 —— 别问它加载了吗.

**换完视觉不等于换完了.** 还差一份 root README —— 仓库根目录那份现在多半还在讲上一个行业,
而它排在你那个漂亮的新首页前面. 这一步最容易漏, 正因为应用本身看起来已经好了.

**最后那个清理动作是不可逆的**, 它会删掉整个 `examples/`, `.claude/` 和 `dataset/`. 所以这
整条线要在一个分支上做, 而且你要留两个 repo: 开发部署那个永久保留, demo 那个是它的产物.

**卡住了别硬扛.** 把三样东西一起给 AI: 你在读哪一篇的路径, 你敲的那条命令, 以及
**终端打出来的原文** (整段复制). 这一篇还可以多附一张页面截图, 视觉问题用文字描述很费劲.

## 2. 要做的事情

1. 读完 README, 重点是第 7 节那个 skill, 第 9 节那三样边界, 第 10 节那两条静默失效的约束.
2. 敲 `/clear` 清空上下文.
3. 敲 `/run-swap-dataset-phase-2-cn`, 跟着它走.
4. **先确认那个 skill 真进了上下文**: 用第 7 节那个问法, 让它复述一条那份文档里的具体主张.
5. 它问调性的时候, 按那五个维度回答, 构图那一条要给出具体形状而不是形容词.
6. 把定下来的那句话写成注释, 放在 `tailwind.config.ts` 顶上.
7. 要求它**一次只改一组文件, 改完停下来**, 不要一次把十几个文件全改了.
8. 做完跑 `mise run build-web`, 确认构建通过.
9. 起 `mise run dev`, 按 README 练习 1 那张单子逐项看过去.
10. 找出还穿着旧衣服的那几处并补上, 再跑一遍那张单子.
11. 确认 `data/` 下的文案一个字都没被顺手改掉.
12. 对 README 练习 2 那四个假想改动, 各回答允许还是碰边界, 以及硬做会坏掉什么.
13. 回答一句: 为什么在这个项目里补一套暗色变体等于什么都没做.
14. **写那份 root README**: 让 AI 出初稿, 你给素材和做验收, 一千词以内, 通读一遍把本课,
    本教程, 我们在这门课里这类措辞全部划掉.
15. 复述一遍整条线那七步, 并说出最后一步为什么不可逆.

**预计用时:** 90 到 150 分钟 (比之前多出来的是写 README 那一步)

## 3. 检查清单

- [ ] **脸换了**: 构建通过, 那张单子上七处全部是新的样子, 并且 agent 页那一侧没有落下.
- [ ] **调性是一句话**: 你的调性覆盖了五个维度, 构图那一条给的是具体形状, 而且写进了配置
      文件顶上的注释.
- [ ] **skill 确认过**: 你用复述具体主张的问法确认过它真进了上下文, 也知道它在仓库里的哪两个
      位置, 以及找不到它的时候那个兜底办法是什么.
- [ ] **力度判据**: 你能说出那句判断标准, 并对自己做的改动诚实回答一句它有没有做到.
- [ ] **三样边界**: 你能说出那三样各是什么和重写之后那个不报错的症状, 其中契约那一样要能
      解释自己写一套围栏分发之后为什么内容检查还会一路全绿.
- [ ] **文案没被动**: 你确认过 `data/` 下的文案一个字都没改, 并能说清顺手改掉会在哪条链上
      开一个洞.
- [ ] **两条静默失效**: 你能说清补暗色变体和派生圆角各自为什么写了没用, 并指出它们的共同点
      是失效而不是错误.
- [ ] **四个改动判断过**: 你对四个假想改动都给出了两个答案, 并能说清为什么其中三个不能靠
      运行一次程序发现.
- [ ] **root README 写了**: 仓库根目录那份 README 讲的是新行业, 一千词以内, 而且全文搜不到
      本课, 本教程, 我们在这门课里这类措辞.
