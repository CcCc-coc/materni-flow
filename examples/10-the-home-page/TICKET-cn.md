# 看懂首页怎么把外行带进门

## 1. 目标

回到第 2 篇那个场景: 你把项目发给面试官, 他点开链接.
**第一屏就是首页, 而他大概率不懂这个行业.**

首页要解决的就是这件事: 把一个外行带到能提出第一个问题的位置. 这一篇讲它靠什么做到, 重点是
那四张能力卡的三层结构.

**这一篇第二个练习练的是一个你后面每一篇都要用的动作**: 看见屏幕上一块字, 把它追回出处.
而且这次要多追一层: 首页那个长说明来自 `data/business-context.md`, 那份文件又是从
的续集.

**最容易糊弄过去的是 tooltip 那一层.** 前两层大多数人半小时能写完, 到 tooltip 会卡住, 然后
很多人的做法是塞几个行业术语进去凑数. 那样等于没写. 判据只有一条:
**拿给一个完全不懂那行的人读, 他读完能不能复述出来.**

---

## 2. 要做的事情

1. 读完 README, 重点是能力卡三层那一节和一份数据两处渲染那一节.
2. 打开首页, 对着 README 第 5 节那四件事, 在屏幕上逐一指出它们分别是哪一块.
3. 悬停在四张能力卡上各看一次气泡, 再用键盘 Tab 过去一次, 再在浏览器开发者工具里切到手机
   尺寸点一次, 确认三种打开方式都 work.
4. 在手机尺寸下注意外侧那一列的气泡贴着哪一边, 想清楚为什么不是居中.
5. 点开那个讲行业背景的覆盖层, 试三种关闭方式, 再试着点面板内部, 确认它不关.
6. 在首页上挑五块看得见的文字, 用第 8 篇的三步法逐一找到它们住在哪个文件.
7. 数一数这五块里有几块住在 `data/` 下面, 有几块住在组件里.
8. 再往上游追一层: 打开 `dataset/` 里 `01-` 开头那份业务背景, 找出和首页覆盖层某一段对得上
   的内容.
9. 开一个叫 `10-the-home-page` 的 branch, 改一条能力卡的 `title`, **重启开发服务器**, 在
   首页和 agent 页各看一次, 确认两处同时变了, 然后还原.
10. 确认工作区里没有留下未还原的改动.

**预计用时:** 60 到 90 分钟 (读正文约 30 分钟)

---

## 3. 检查清单

- [ ] **四件事指得出**: 你能在首页上逐一指出那四件必须做到的事分别对应哪一块.
- [ ] **三层的分工**: 你能说出概念名, 一句白话, 两三句解释各写给谁看, 以及为什么中间那句是
      唯一有机会留住陌生人的东西.
- [ ] **气泡三种入口验过**: 悬停, 键盘, 手机点按你都试过, 能说清只做悬停会漏掉谁; 也在窄屏
      下看过外侧那列的气泡贴着哪一边, 能说清为什么不能居中.
- [ ] **一份数据两处渲染**: 你改过一条卡片, 亲眼看到两个页面同时变; 并且能说清两份配置描述
      同一件事时, 漂移为什么不会有任何测试失败.
- [ ] **五块字追到了**: 你能说出首页那五块文字各自住在哪个文件, 也发现它们全都在 `data/` 下面.
- [ ] **追到了源头**: 你打开过 `dataset/` 里那份业务背景, 找到了和首页覆盖层对得上的内容.
- [ ] **换领域改哪儿**: 你能说出换一个业务领域时首页要动哪几段, 以及组件要不要改.
- [ ] **重启这件事知道了**: 你能说清改完 `data/` 下的文件为什么要重启开发服务器, 以及改组件
      代码为什么不用.
- [ ] **工作区干净**: 练习改的文案都还原了, `git status` 是干净的.
