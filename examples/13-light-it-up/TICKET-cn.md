# 把整个 app 点亮

## 1. 目标

前面八篇一个账号都没让你注册. 这一篇要花钱了, 而这是整门课**唯一一次真正的门槛**.

要补三样东西: 一把模型的 API key, 一个云端 PostgreSQL, 以及库里的数据. 三样缺一样 agent
都不工作, 但坏的样子不一样, 这一点本身就是这一篇要教的东西.

**这一篇是纯操作篇, 原理都不在这里.** 数据集是什么在第 14 篇, 同步为什么这么做在第 15 篇,
配置系统怎么设计的在第 30 篇. 现在只管把它点亮.

**关于钱, 一条红线**: 拿到 key 之后第一件事是在控制台里给它设一个 5 到 10 美元的花费上限.
这门课全程的调用成本是几美分到一美元的量级.
**上限防的不是这门课, 是一把泄漏出去的 key 被别人跑满.**
不设上限的 key 是一张空白支票.

**还有一条容易忘的**: 改完 `.env` 必须重启开发服务器. 配置是进程启动时读进去的, 不重启,
跑着的那个进程手里还是旧的.

这一篇涉及两个外部平台, 它们的界面隔几个月就改版. 卡在某一屏上时不要硬猜,
**把那一屏截图丢给助教, 要求它一步一步带你走**. 这是第 4 篇那套方法的第一次真实应用.


**卡住了别硬扛.** 把三样东西一起给 AI: 你在读哪一篇的路径, 你敲的那条命令, 以及
**终端打出来的原文** (整段复制, 不要截图, 不要只说一句报错了).
粘贴前先把连接串和 key 的片段打码.

## 2. 要做的事情

1. 开一个叫 `13-light-it-up` 的 branch.
2. 在 OpenAI, Anthropic, Google 三家里选一家, 去它的开发者控制台拿一把 API key. 注意订阅
   和 API 额度是两回事, 有 ChatGPT Plus 不等于有 key.
3. 在那家控制台里给账号设一个 5 到 10 美元的消费上限, 把 key 存进密码管理器, 再填进 `.env`
   里对应的那个变量.
4. 打开 `.env.defaults`, 确认 `LLM_PROVIDER` 指的和你拿到 key 的是同一家, 不是就改过来.
5. 打开你的 Neon 项目, 取出主机名, 用户名, 密码, 数据库名四个值填进 `.env`, 主机名用带
   pooler 的那一个.
6. 跑 `mise run cli-test-db-conn`, 确认能连上; 连不上先解决它再往下走.
7. 跑 `gen-data` 把本地种子造出来, 记下它最后打印的文件名和大小.
8. 跑 `sync-db`, 看它一张表一张表报进度, 把那个顺序抄下来.
9. 跑 `verify-db`, 确认每张表的行数都一致.
10. 跑 `mise run kill` 再 `mise run dev`, 打开 agent 页.
11. 点一个 kickstart 按钮, 确认拿到的是带真实数字的回答, 并和第 5 篇抄下的那条报错对一眼.
12. 做一遍拿掉一样东西的练习: 分别让 API key 和数据库主机名各失效一次, 记下报错出现在哪儿,
    说得清缺什么吗, 每次看完立刻还原. 第三种坏法 (拿掉数据) 留给第 15 篇.
13. 确认工作区回到干净状态, `.env` 里的真值都在, 两处临时改动都还原了.

**预计用时:** 60 到 100 分钟 (注册账号和造数据本身要等)

## 3. 检查清单

- [ ] **key 就位且有上限**: 三家里选了一家拿到 key, 在控制台里设了 5 到 10 美元的消费上限,
      key 存进了密码管理器, 没有出现在任何聊天记录或 Git 提交里; 你也能说清月费订阅和 API
      key 分别买的是什么.
- [ ] **供应商对得上**: `.env` 里那把 key 和 `.env.defaults` 里的 `LLM_PROVIDER` 指的是同
      一家.
- [ ] **数据库连得上**: `mise run cli-test-db-conn` 是绿的, 而且你能说清这条命令为什么故意
      不查任何表.
- [ ] **数据到齐了**: `verify-db` 逐表行数全部一致, 没有 exit 1; 你也能说清同步成功和数据
      到齐为什么是两件事.
- [ ] **端口和主机名分家**: 你能说清端口为什么进 `.env.defaults`, 而主机名进 `.env`.
- [ ] **agent 真的答了**: 点一个 kickstart 按钮拿到带真实数字的回答, 第 5 篇那条报错不再
      出现.
- [ ] **两种坏法都见过**: 你分别让模型和数据库失效过一次, 能说出这两条报错里哪一条更含糊,
      以及为什么是它.
- [ ] **重启这件事**: 你能说清为什么改完 `.env` 光刷新浏览器没用.
- [ ] **工作区干净**: 两处临时改动都还原了, `git status` 里没有留下未还原的东西.
