# 在自己的机器上把它跑起来

## 1. 目标

这是这门课第一次动手. 走完三步, 你的机器上会有两个开发服务器在跑, 浏览器里的首页能打开.

三步是装依赖, 配密钥, 起服务.

**这一篇的终点故意定得低: 首页能看能点就算过.** agent 页这时候还不能用, 因为数据库里一行
数据都没有 —— 造数据和发布数据是数据那一组 (第 17 到 20 篇) 的事. 你点 kickstart 拿到报错
是**正常的**, 不是你哪儿做错了.

为什么这么切? 因为第一次在一个陌生项目上动手, 最重要的是尽快拿到一个能回头对照的正常状态.
一口气全配完, 卡在哪一步都很难判断.

真正要用心的是第 2 步. **配置的错误几乎都不报错**: 从模板抄一行忘了注释掉, 或者把值填进
错的那个文件, 程序照跑, 只是读到的不是你以为的那个值.

还有一条关于钱的红线: **拿到 LLM 的 API key 之后, 第一件事是给它设一个花费上限.** 5 到 10
美元就够, 这门课大概率用不完. 不设上限的 key 是一张空白支票, 而它只要泄漏一次就会被跑满.

这一篇也是这门课第一次用 AI skill. 卡住了别硬扛, 把助教叫起来, 但一定要求它**一步一步** 走.

---

## 2. 要做的事情

1. 从这门课那个基线 branch 开一个叫 `04-get-it-running` 的 branch, 后面凡是要改仓库里的
   文件都在它上面做.
2. 装好 mise, 然后跑 `mise run inst` 装齐 Python 和 Node 两套依赖.
3. 复制 `.env.example` 成 `.env`, 填上四个 `DB_` 开头的值, 其余保持注释.
4. 在 OpenAI, Anthropic, Google 三家里选一家, 去它的开发者控制台拿一把 API key. 注意订阅
   和 API 额度是两回事, 有 ChatGPT Plus 不等于有 key.
5. 在那家控制台里给账号设一个 5 到 10 美元的消费上限, 然后把 key 存进密码管理器, 再填进
   `.env` 里对应的那个变量.
6. 打开 `.env.defaults`, 把 `LLM_PROVIDER` 改成你选的那一家, 或者在 `.env` 里写一行同名的
   盖掉它.
7. 跑 `mise run dev`, 等两个服务器都打出就绪日志 (Next.js 打 `Ready in`, uvicorn 打
   `Application startup complete.`).
8. 打开浏览器访问本地 3000 端口, 确认首页完整渲染, 四张能力卡都在, 解释气泡能弹出来.
9. 点右上角进 agent 页, 点一个 kickstart 按钮, **看它怎么失败**, 读那条失败信息.
10. 至少一次, 敲 `/showcase-learn-cn` 或 `/about-bi-agent-app-scaffold-cn` 把助教叫起来:
    要么把这一篇里你没看懂的那段原样复制给它追问到懂, 要么要求它一步一步带你走上面某一段,
    并且不许它一次性做完.

**预计用时:** 40 到 70 分钟 (装依赖本身要等几分钟)

## 3. 检查清单

- [ ] **branch 开好了**: 你从基线开了一个以这一篇命名的 branch, 后面的改动都在它上面.
- [ ] **依赖装齐**: `mise run inst` 跑完没有报错, `.venv` 和 `node_modules` 都在.
- [ ] **配置分对了家**: 你能说出自己往 `.env` 里填了哪几个值, 并解释为什么 `SCHEMA_NAME`
      不在那里面.
- [ ] **API key 就位且有上限**: 三家里选了一家拿到 key, 在控制台里设了 5 到 10 美元的消费
      上限, key 存进了密码管理器, 没有出现在任何聊天记录或 Git 提交里; 你也能说清月费订阅和
      API key 分别买的是什么.
- [ ] **服务器起来了**: 两个服务器都打出了就绪日志, 浏览器能打开首页, 页面完整渲染, 能力卡
      和解释气泡都正常.
- [ ] **知道自己停在哪**: 你点过 kickstart 并看到它失败, 能说清这是因为库里还没数据, 而不是
      环境配错了; 也知道补上它是第 17 到 20 篇的事.
- [ ] **助教用过一次**: 你加载过这门课的 skill, 拿它问过一段没看懂的正文或者带你走过一段
      操作; 你能说清为什么不该让它一次性把环境配好, 也能说清为什么读不懂时不该直接翻过去.
- [ ] **配置的错不报错**: 你能举出至少一种填错了程序照跑的情况, 比如从模板抄来忘了注释掉
      的那一行.
