# 确认四门前置课你都会

## 1. 目标

这一篇不教新东西, 也没有练习. 它是一道闸门: 把这门课默认你已经具备的四块技能摊开写出来,
让你当场判断自己缺哪一块.

**这一篇的红线是不要凭印象过关.** 自检清单上每一条的判据都是你能不能现在就做出来,
而不是我好像见过. 见过和做得出来之间隔着的距离, 会在后面某一篇上以卡壳的形式收回去.

前置知识缺失有个特点: 它不像我这段没看懂, 它像这个教程写漏了一步. 于是人会一遍遍回头
翻这门课的文档, 去找一个根本不在这里的答案. 现在花十分钟对一遍, 比后面卡住再回头便宜得多.

四门课里**云端 Postgres 那门最硬**. 这个应用在任何环境下都读同一个远程 PostgreSQL, 本地
开发也一样, 没有本地数据库兜底. 没有一个 Neon 实例, 下一篇就走不下去.

---

## 2. 要做的事情

1. 读完这个 Task 的 README, 重点是第 9 节那张表, 它告诉你每门前置课在哪一篇会被用到.
2. 对着第 10 节的自检清单逐条过一遍, 把答不上来的条目记下来.
3. 按记下来的条目定出要补哪几门课, 并按 README 建议的顺序排一下: 先 dev tools, 再 Neon
   Postgres, 然后 SQLite 和 Vercel.
4. 去学要补的那几门课, 学完再回到这一篇重新过一遍自检清单.
5. 在终端里敲 `mise --version`, 确认能拿到版本号.
6. 打开你的 Neon 控制台, 确认有一个可用的 Postgres 项目, 并找到 host, user, password,
   database 这四个值放在哪里 (先不用填到任何地方, 下一篇才用).
7. 用 DBeaver 或者 Neon 网页控制台连上那个实例, 跑一句 `SELECT 1`, 确认真的通.

**预计用时:** 已经四门都会的话 15 分钟. 要补课的话按缺几门算, 每门 2 到 4 小时.

---

## 3. 检查清单

- [ ] **四块技能清楚**: 你能说出这门课默认你已经具备的四块技能分别是什么, 各出自哪门课.
- [ ] **用在哪里清楚**: 你能说出至少三处后面会用到它们的地方, 比如哪一篇要用 mise, 哪一篇
      要用 Neon 的连接信息.
- [ ] **自检过了一遍**: 十四条自检你逐条判断过, 并且明确知道自己哪几条答不上来.
- [ ] **缺的已经补完**: 答不上来的那几条对应的课已经学完, 回头再过一遍能全部答上来.
- [ ] **mise 可用**: 终端里 `mise --version` 能拿到一个版本号.
- [ ] **Neon 实例就位**: 你有一个能用的 Postgres 项目, 并且知道那四个连接值在控制台的哪里.
- [ ] **连得上**: 你用 DBeaver 或 Neon 网页控制台连上那个实例, 跑通了一句 `SELECT 1`.
- [ ] **知道为什么最硬**: 你能解释为什么云端 Postgres 是四门里最硬的前置, 理由要落在这个
      应用本地开发也读远程库这件事上.
