# MaterniFlow

MaterniFlow 是一个面向模拟产科病房的对话式运营工作台。它把交班时最需要共享的现场信息放在一起：哪些床位现在可用、谁正在值班、哪些提醒需要关注、接下来安排了什么操作。它服务的是交班前后的几分钟——这时答案要清楚、可追溯，比再多一个仪表盘更重要。

## 能做什么

用自然语言提问，得到基于 PostgreSQL 病房快照的回答。数据包含 11 张表和 355 条合成记录，覆盖交班、床位容量、风险监测和照护排程四条主线。回答可以是简洁说明，也可以自动呈现为表格、图表或交班流程。

## 本地运行

需要 Python 3.12、`uv`、Node.js、`pnpm` 和 PostgreSQL。

```bash
cp .env.example .env
mise run inst
mise run dev
```

网页默认运行在 3000 端口，API 运行在 8000 端口。启动前，在 `.env` 中配置数据库连接和模型凭据。

## 工作方式

Python 服务读取当前 PostgreSQL schema，将结构压缩成模型能使用的上下文，并提供只读 SQL 工具。Next.js 前端负责流式呈现回答：普通 Markdown 保持易读，表格、图表和流程图围栏则交给对应的视觉组件渲染。

项目最重要的取舍，是把行业知识放在内容层，把应用边界保持稳定。提示词、网站文案和数据库 schema 可以描述新的运营场景，而不必重写聊天传输、渲染管线或数据库安全规则。SQL 在始终回滚的事务中执行，因此只读是运行时属性，不只是提示词里的约定。
