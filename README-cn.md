# 核心作品脚手架 总览

> 一句话: 造一个能用大白话查数据库的 agent 应用, 并且守住让它能换行业的那些边界.
> 想先了解全貌, 看 [README-ORIGINAL-cn.md](README-ORIGINAL-cn.md).

## 1. 这门课是什么

你会亲手搓出一个部署在公网上的 AI Agent 商业分析应用: 一个多表 PostgreSQL 数据库, 一个会自己写 SQL 去查它的 agent, 一个把这门生意讲给外行听的网站. 它不是玩具 —— 部署, 架构和边界全部按企业级的来, 而且它**天然是一个多领域交叉的东西**, 你几乎一定会在里面撞见自己没碰过的领域. 有意思的地方还不止于把它做出来, 而在于**换掉数据和领域知识, 它就是另一行的应用** —— 而这件事成立, 靠的是一堆破了不报错的边界.

这是一个 showcase 类型的教学仓库: 整个 repo 就是一门课, 内容拆成 [examples/](examples/) 下一个个按编号排列的 Task. 它不只是让你学会, 还让你在学完后抹去教学痕迹, 把这个 repo 当作自己的作品拿去面试展示. 你不需要把它当作从头读到尾的教材, 而是照下面**怎么学** 那一节的路子走一遍.

---

## 2. 怎么学

1. 进 [examples/](examples/), 从 01 开始按编号往下刷. 第一篇是索引, 会给你整门课的地图, 包括那条**做一次, 懂一层, 再做一次** 的节奏, 以及唯一那处要注册账号花钱的门槛排在哪儿.
2. 每个 Task 都照它自己的 TICKET 做完再往下.
3. 学的过程中有两个帮手随叫随到: `/showcase-learn-cn` 是带学教练 (要地图, 要某一处讲透, 要决定下一步, 或卡住了都找它, 环境 setup 也由它带); `/showcase-quiz-cn` 是面试式自测, 检验你是不是真的学懂了.
4. 学到什么算成: 用 `/showcase-quiz-cn` 测到 70% 的题都能思路清晰地答出来.

---

## 3. 学完之后: 展示与发布

showcase 的落点是把这段经历讲出去, 并把这个 repo 变成你自己的作品. 学完全部 Task 后, 再用两个帮手收尾:

1. `/showcase-demo-cn` 陪你排练**我是怎么做出这个项目的** 这段故事: 开场五分钟那条固定路线, 完整的七幕, 以及被追问时怎么接住.
2. `/showcase-publish-cn` 把这个 repo 抹去所有教学痕迹, 转成一个可以放上你自己 GitHub 的 portfolio repo, 再做一次敌意扫描, 假设读者就是在找这是不是一个教学项目的破绽.

顺序是先用 `/showcase-demo-cn` 排练好怎么讲, 再跑 `/showcase-publish-cn` 清理发布 (publish 会把排练用的底稿本身也一并清掉).

---

## 4. 学完你能做到什么

你能从零把一个前后端同仓库的 AI 应用送上公网, 说得清哪些配置跟着 git 走哪些必须手填; 能把一个陌生行业的业务材料整理成数据字典, 再蒸馏成 agent 的领域知识; 能判断一个工具该怎么切, 说明该怎么写, 安全边界该放在哪一层. 你能在几个小时之内把这整套东西换成另一个领域, 知道那个换得成立是靠什么撑住的, 并且对着别人把这件事讲清楚, 接得住追问.

而这些能力横跨了 Business Analyst, Data Scientist, Data Engineer, Machine Learning Engineer, SDE, AI Engineer, Finance Engineer 与 UX 八个方向 —— 每一块这门课都只带你做到能跑, 但每一块都留着口子. **什么都会一点, 然后按你的目标岗位挑一个往深里挖**, 那正是最后一篇要跟你聊的事.
